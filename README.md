# 🌱 Habitly – Build Better Habits, One Day at a Time

Habitly is a habit-tracking application designed to help users build positive habits, stay consistent, and track their daily progress. It provides a simple and user-friendly way to organize routines, monitor personal goals, and improve productivity.

## ✨ Features

- **Habit Management** – Create, update, and manage daily habits.
- **Daily Tracking** – Track completed habits every day.
- **Progress Monitoring** – Monitor your consistency and improvements.
- **User-Friendly Interface** – Simple and intuitive design.
- **Personal Goals** – Build routines and work toward personal goals.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/prajwal82appu/habitly-.git
```

### 2. Navigate to the project directory

```bash
cd habitly-/habitly
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

_Note: These commands assume the project uses Node.js and npm. Adjust them according to your actual project setup._
