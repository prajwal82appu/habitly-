# Habitly 🔥

Week 1 of the CodGen Frontend Development Internship: a static, responsive habit tracker layout built with only HTML and CSS.

## Features
- Semantic HTML (`header`, `main`, `section`, `footer`)
- CSS variables for colors, spacing, radius and shadows
- CSS Grid layout: 1 column on phones, multi-column on tablet and laptop
- Hover and focus states on cards and buttons
- Tested at 360px, 768px and 1280px

## Run locally
Open `index.html` in any browser. No build step needed.

## Deploy on GitHub Pages
1. Create a repo named `habitly` and push these files to the repo root.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. Your site goes live at `https://<your-username>.github.io/habitly/`.
